# Modern Interior Design Website

A clean, professional website for a full-service residential and commercial interior design company. Features portfolio showcase, services overview, and contact information with modern web design principles.

## Tech Stack

- **HTML5** - Semantic structure and accessibility
- **CSS3** - Modern layouts and responsive design
- **Vanilla JavaScript** - Interactive elements and smooth animations

## File Structure

```
Modern-interior/
├── index.html          # Main landing page
├── style.css           # Styling and layout
├── script.js           # Interactive features
├── images/             # Portfolio and design images
└── README.md           # Project documentation
```

## Quick Start

1. **Clone the repository**
   ```bash
   git clone https://github.com/pabloWIB/Modern-interior.git
   ```

2. **Open index.html** in your browser

3. **View the website** - ready to use locally

## Customization

**Update content:**
- Edit company info and services in `index.html`
- Replace portfolio images in the `images/` folder
- Modify contact details and designer information

**Style changes:**
- Customize colors and fonts in `style.css`
- Adjust layout and spacing for different screen sizes
- Update navigation and section styling

## Deployment Options

Deploy your interior design website for free:

- **GitHub Pages** - Enable in repository settings
- **Netlify** - Drag and drop deployment
- **Vercel** - Connect GitHub repository
- **Surge.sh** - Command line deployment
